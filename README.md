# StudySphere - Web-Based Learning System

A web-based learning platform where students can access course materials and take quizzes, with an admin area for managing content. Built as a **group academic project** (Group F).

## Technologies
- ASP.NET Web Forms (C#)
- SQL Server (database scripts in `/Database`)
- HTML, CSS, JavaScript, Bootstrap

## Features
**Student:** register and log in, browse courses, view learning content and videos, take quizzes and view results, track progress, student dashboard.

**Admin:** admin login, manage users, courses, learning resources and quizzes, admin dashboard.

## How to run
1. Open `StudySphere.slnx` in Visual Studio.
2. Create a database named `StudySphereDB` in SQL Server Express and run the scripts in `/Database`.
3. Check the connection string in `Web.config` matches your SQL Server instance.
4. Restore NuGet packages and run the project.
